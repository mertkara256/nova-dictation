# Usage

[Türkçe](kullanim.md) · **English**

How Nova Dictation behaves, in detail. Setup, command examples and shortcuts are in the [README](../README.en.md).

## Voice commands

Commands start with a command word. The default word is “Nova”, and it can be changed with the **Ayarlar** (Settings) button at the top right. Commands can be said in the middle of speaking while the microphone is on. A command is not written into the text; what is said before and after it keeps being written. The **Komutlar** (Commands) button under the text, or “Nova, komutları göster”, opens the full list. The box at the top of the list searches it, ignoring case and Turkish letters (typing “sec” also finds “seç”). In the search box, Esc clears the search first.

- Dictation is written at the caret, or in place of the selection if there is one. While the microphone is on, the caret position is shown as a thin line in the text area.
- Commands given with “bunu” (this), such as delete, select, capitalize or put in quotes, apply to the selection, or to the last dictated part if nothing is selected. Commands given with a word apply to the last place that word appears in the text, together with a suffix attached with an apostrophe (“ayşe hanım kelimelerini sil” deletes all of “Ayşe Hanım'a”); only “X yerine Y yaz” (write Y instead of X) leaves the suffix in place. If the word does not appear as it is, a form with a suffix attached is looked for: if the text only has “Raporu” (the report, accusative), “rapor kelimesini seç” (select the word rapor) selects it (for words of at least three letters; “X yerine Y yaz” and “X kelimesinden Y kelimesine kadar seç”, select from X to Y, need an exact match). Only plural, possessive and case suffixes, and “-ki” after the locative (“Toplantıdaki”, the one in the meeting), count: searching for “rapor” finds “Raporlarımızdan”, but searching for “gün” (day) does not find “Güneş” (sun); if no fitting word is found, the text stays as it is and Nova says it was not found. When a word is deleted, the comma that separates it in a list goes too (deleting “armut” from “Elma, armut, muz.” leaves “Elma, muz.”); if the first word of a sentence is deleted, the next word starts with a capital letter.
- After each command, a note at the bottom of the screen says what was done and offers an **Geri al** (Undo) or **Yinele** (Redo) button.
- What is said in one go, without a pause, counts as one change; a later “geri al” (undo) undoes all of it together. A “geri al” said within the same words undoes only the last change before it (“son cümleyi sil, son cümleyi sil ve geri al” — delete the last sentence twice, then undo — undoes only the second deletion).
- Commands can also be given without saying “Nova”: while **⌃ Control** is held down, what you say is not written into the text but applied as a command (for example, “son cümleyi sil” while holding ⌃). Command mode starts once the key has been held on its own for about a quarter of a second, so shortcuts like ⌃C are not affected. If the microphone is off, it turns on for as long as the key is held. If the key is released before the last word ends, the app waits for the word to end (at most half a second); if you had already stopped speaking, it does not wait. Several commands can be said in a row (“son cümleyi sil ve yeni satır”, delete the last sentence and new line); a command that is not understood is not added to the text, only reported. This feature works while the Whisper server is running; if Whisper cannot be reached while ⌃ is held, the app does not switch to browser recognition, so nothing said is written into the text. While ⌃ is held, Whisper is given the command list as a hint; in the speech scan this made commands come out right more often, mostly when spoken fast.
- You can say “Nova” and pause: after the command word on its own, the app waits for a command and shows this under the text. If what follows is not a command, both are written as text.
- Commands can be chained with “ve” (and): “Nova, son cümleyi sil ve yeni satır” (delete the last sentence and new line), “Nova, kırmızı yerine mavi yaz ve yeşil yerine sarı yaz” (write blue instead of red and yellow instead of green). If the part before “ve” is not a command on its own, “ve” belongs to the command: “Nova, kırmızı yerine mavi ve yeşil yaz” (write blue and green instead of red) is a single replacement.
- “Kes” (cut) deletes the text and copies it to the clipboard. Text selected by hand is cut exactly: if part of a word is selected, only those letters go, and the whole selection (including its period or line break) is copied; if whole words are selected, no double space is left behind. “Yapıştır” (paste) writes the text last cut or copied in Nova exactly as it is, with its punctuation and line breaks, in place of the selection or at the caret; it does not paste text copied in other apps, because reading the clipboard needs a separate browser permission. To move a sentence, say “Nova, son cümleyi kes ve başa git ve yapıştır” (cut the last sentence, go to the start and paste), or simply “Nova, son cümleyi başa taşı” (move the last sentence to the start).
- Commands are applied to Whisper's final text; small speech recognition typos (for example “son cümle isi”, “No va”) are tolerated. In the verb of a delete or select command, at most one letter of difference is tolerated; commands that delete or select the whole text (“her şeyi sil”, “hepsini seç”) need the verb said exactly: “Nova, hepsini say” (count all of it) does not delete the text; it is written into it. When Whisper writes “geri al” (undo) in the past tense (“geri aldı”, “üç kere geri aldım”), it still counts as undo. The negative of a command does not count as one: “Nova, her şeyi silme” (don't delete everything) does not delete the text; it is written into it.
- A phrase that starts with the command word but is not recognized is added as text, and the screen says so.
- Whisper occasionally misses the “Nova” at the start; the command is then written as text. If a part said without the command word matches a command as a whole (for example “Son cümleyi sil.”, delete the last sentence, on its own), it is still written as text, but a **Komut olarak uygula** (Apply as command) button appears at the bottom of the screen: the written phrase is taken back and the command is applied; a later “geri al” (undo) returns to the text as it was before the phrase was said. The button shows for a few seconds and goes away if the text changes in the meantime.

## Workspace

- **Getting started:** On the first visit without an existing draft or recovery copy, a guide opens automatically. Reopen it through **Ayarlar → İlk kullanım rehberi** (Settings → Getting started). It shows service/model readiness and links to setup instructions. **Mikrofonu dene** (Test microphone) requests permission only after a click, checks the audio level for five seconds, and neither records nor transmits audio. It closes the microphone when the check ends or the panel closes. In the third step, the delete, undo and new-paragraph commands are tried by speaking: what you say after pressing the guide's own **Mikrofonu aç** (Turn on microphone) button goes only into a separate sample text, leaving the draft untouched. A command applied by voice gets a “✓ Söylendi” (said) mark, and the last thing heard is shown; once all three work, the guide says so. The same commands can also be tried with buttons; if the browser has no speech recognition, only the buttons appear. Dictation into the main text is disabled while the guide is open, and a note under the editor says so.
- **Notes:** The **Notlar** (Notes) panel in the toolbar lists the notes in this browser, most recently changed first; clicking a note opens it. **Yeni not** (New note) opens an empty note, unless the open note is already empty. An empty note that was never written in leaves the list when you switch to another note. Deleting a note asks for confirmation. Each note keeps its own undo history for the session: after coming back from another note, undo still works in that note, and it never carries changes over from one note to another. The single draft from before notes becomes the first note on first launch. Notes cannot be switched while the microphone is on or pending audio is being transcribed; what was said so far goes into the open note. A delete confirmation that was already open does not work either once the microphone is on. If the app is open in more than one tab, each tab writes to its own open note; a note deleted in one tab comes back if it is still open in another tab and something is written in it. A tab does not save a note nothing was written in, so if the same note changed in another tab, closing this tab or switching notes here does not overwrite the newer text. If both tabs wrote in it, the last one to write wins. A note you come back to from another note opens with its current text if it changed in another tab meanwhile; its earlier undo history is not carried over.
- **Draft saving:** The open note is kept in the browser as you write; after a reload or reopening, you continue where you left off. If all text was deleted before a reload, the text shown just before it was deleted is kept; while that note is open and empty, the app offers to bring it back with **Geri getir** (Restore), and does not offer it in another note.
- **Save status:** Nothing is shown while saving works. If the draft cannot be saved (e.g. browser storage is blocked or full), a warning appears below the editor with **Kaydetmeyi yeniden dene** (Retry saving) and **Metni indir** (Download text); it stays until a save succeeds. If a recovery copy cannot be saved when clearing text, the last saved draft is preserved.
- **Command word:** In the **Ayarlar** (Settings) panel, “Nova” can be replaced with another word that is easy to say (for example a name). The word must be a single word of at least 3 letters and is stored in the browser. The command is recognized even if speech recognition splits the word into syllables (“No va”). For words of 5 or more letters, a one-letter typo is also tolerated (for example “Carvis” instead of “Jarvis”), as long as a recognized command follows it. Suffixed forms of the word (“Asistana”) do not count as the command word.
- **Custom words:** In the **Ayarlar** (Settings) panel, frequently used names and terms (for example “Ayşe Hanım, Kubernetes”) can be listed, separated by commas or one per line, up to 50. They are sent to Whisper as a hint with each final-text request, which makes it more likely to use these spellings. Whisper sometimes takes a hinted word for a proper noun and splits its ending off with an apostrophe (“Grafana” → “Grafan'a”); such splits are joined back.
- **Service status:** The badge next to the title shows speech recognition readiness (green: ready, yellow: offline or loading the model). Whisper's `/health` response confirms model readiness; dictation cannot start while the model is loading. The getting-started guide offers a manual recheck. While Whisper is off, hovering over the badge shows how to start it.
- **Toolbar:** Under the text are the word count and the **Kopyala** (Copy), **İndir** (Download, as plain text or Markdown) and **Temizle** (Clear) buttons. Clearing can be undone too.
- **Command history:** The **Geçmiş** (History) panel lists the commands given in this session, by voice or by button, with their time and result; commands that could not be carried out are shown in red.
- **Panels:** On wide screens (at least 1024 pixels), the Notes, Commands, History and Settings panels and the getting-started guide open to the right of the text, so the text stays in view while you read the commands; a long list scrolls inside the panel. On narrower screens and phones they open below the text.

## Speech recognition

By default, **Whisper large-v3-turbo** (OpenAI) runs on your computer. It is free, and no audio is sent anywhere.

- **While speaking:** The audio so far is sent to Whisper about once a second, and the result appears in gray after the text. Words arrive in groups, about one or two seconds behind the speech, rather than one by one. Because the audio is cut mid-word when it is sent, the last word is often incomplete; it is therefore hidden and arrives in full with the next update.
- **When you pause:** That part is sent to Whisper once more, and the final text with punctuation replaces the gray text. Commands are applied to this final text.
- On very short audio (for example a one-syllable “kes”, cut), Whisper can make up sentences left over from video subtitles: “İzlediğiniz için teşekkür ederim.” (thank you for watching), “Altyazı M.K.” (subtitles by M.K.). If a part shorter than two seconds comes back as only one of these sentences, it is not written.
- If the Whisper server is not running, the microphone stays off and the screen shows how to start Whisper; the app does not switch to another recognizer on its own. If you choose **Tarayıcının tanımasıyla devam et** (Continue with the browser's recognition), the browser's speech recognition (Web Speech) is used and the screen says so. Web Speech sends the audio to Google (Chrome) or Apple (Safari). This permission lasts while the page stays open and is not saved; it is asked again when the page is reopened. Even after permission is given, Whisper is tried first each time. Web Speech adds no punctuation in Turkish; the app treats each part that arrives at a pause as a sentence and ends it with a period. Commands with ⌃ are not available in this mode. The demo, by contrast, uses the browser's recognition directly and says so at the top of the page.
- A transcription request is cancelled if it does not complete within 30 seconds. A transient connection failure is retried once automatically; a timeout is not. If final transcription fails, the microphone closes and unprocessed audio stays in this tab's memory. **Yeniden dene** (Retry) processes these parts in order without reopening the microphone or repeating text already inserted. Pending text and commands apply at the cursor/selection in effect when retried. This failure does not automatically switch to browser recognition.
- “Nova, duraklat” (pause; or “bekle”, wait) pauses listening without turning off the microphone: until “Nova, devam et” (resume) is said, nothing spoken is written, no command is applied and no gray text is shown. Turning off the microphone ends the pause. With the browser's recognition the audio goes to Google, so “duraklat” turns the microphone off.
- Stopping the microphone normally finishes the last spoken words. “Nova, dinlemeyi durdur” (stop listening; or “mikrofonu kapat”, turn off the microphone) instead writes nothing said after the command: words that follow without a pause are dropped too, and audio not yet transcribed is discarded. While processing a normal stop, **Bekleyen sesten vazgeç** (Discard pending audio) cancels the request and discards unprocessed audio; it is also available after a failure. Existing text is preserved. Pending audio is not saved to disk and is lost when the page closes. Requests for finished or discarded previews are also cancelled.
